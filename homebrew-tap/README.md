# chaiwithcode/homebrew-tap

Official Homebrew tap for [ChaiWithCode](https://github.com/chaiwithcode) applications.

## Installation

Install Loom directly:

```bash
brew install --cask chaiwithcode/tap/chaiwithcode-loom
```

Or tap the repository first:

```bash
brew tap chaiwithcode/tap
brew install --cask chaiwithcode-loom
```

## Available Casks

| Cask | Description |
| :--- | :--- |
| `chaiwithcode-loom` | Native macOS menu bar monitor for local AI coding agents |
