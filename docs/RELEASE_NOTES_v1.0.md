## Loom 1.0

Official 1.0 release of Loom, the local-first macOS session and quota monitor for AI coding agents.

### What's Changed

- **Multi-Provider Loom Quotas Widget**: All-new macOS desktop widgets across Small, Medium, and Large families supporting Codex, Claude Code, and Antigravity with live remaining percentages and reset timers.
- **Provider-Level Storage Monitoring**: Native compact menu-bar Storage view and detailed drill-down in Settings displaying local disk footprint for agent directories, caches, and logs.
- **Visual Hierarchy Polish**: Primary remaining percentages, clean desktop chrome, and subdued comparative usage bars.
- **Settings Window Sizing**: Fixed vertical sizing and minimum dimensions across all Settings tabs.
- **Verified Provider Identity**: Official brand marks for Codex, Claude, and Antigravity with robust bundle discovery and fallback resilience.
- **Sparkle 2 & Homebrew Distribution**: Automated signing, Hardened Runtime, Apple notarization, and official distribution tooling.

### Requirements

- macOS 14.0 Sonoma or later
- Apple Silicon (arm64)
