## Loom v0.1.1

Maintenance release improving Loom's software update experience.

### What's Changed

- **Embedded Release Notes**: Sparkle release notes are now embedded directly in the update dialog.
- **Version History**: The "Version History" link now points directly to official GitHub Releases.
- **Update Feed Improvements**: Update-feed generation and validation were improved.

### Requirements

- macOS 14.0 Sonoma or later
- Apple Silicon (arm64)
