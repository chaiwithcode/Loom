Why Loom?

What are all my local AI coding agents doing on my Mac right now?

When you juggle multiple autonomous agents across terminals, editor extensions, and language servers, visibility evaporates.

Terminal & Process Sprawl

Codex in VS Code, Claude Code in Terminal tabs, and Antigravity running background helpers. Loom discovers all active agent processes and groups them into clean, logical project sessions.

Invisible Rolling Quotas

Quota exhaustion can interrupt a refactor. Loom surfaces observed quota percentages and reset windows for Codex and Antigravity, with warnings below 15%, critical alerts below 5%, and notifications when fresh telemetry confirms replenishment.

100% Local & Ephemeral

No Loom account, no cloud relay, and zero telemetry SDKs. Loom is strictly read-only, communicates over local stdio and loopback HTTPS, and never persists sensitive provider tokens.

Live Monitoring

Local Agent Sessions

Know immediately which repository each agent is editing, what phase it is executing, and when it needs your input.

  • Glanceable Provider Selector Switch between OpenAI Codex, Anthropic Claude Code, and Google Antigravity with live session counters.
  • Normalized Lifecycle States Truthful status indicators for working, idle, waiting for input, starting, finished, and failed.
  • Process Tree & Directory Inspector Expand any session to inspect helper PIDs, host apps, Git branches, working paths, and a one-click Reveal in Finder action.
Telemetry & Diagnostics

Usage Quotas & Local Storage

Track rate limits and inspect agent disk consumption without touching terminal commands or third-party web portals.

  • Truthful Live Quotas View observed remaining percentages and reset windows for Codex and Antigravity. Loom can warn below 15%, send critical alerts below 5%, and notify when fresh telemetry confirms replenishment. Claude Code quota is not exposed by its upstream local interface, so Loom labels it unsupported instead of showing a made-up value.
  • On-Demand Local Storage Audit Measure allocated disk space across agent stores, transcript logs, and cache folders. Scans run cooperatively in the background without reading file contents or traversing symlinks.
  • Path Concealment Mode Mask repo directories and sensitive disk paths with one toggle in Settings for secure screen sharing and live streaming.

Desktop Integration

Native macOS Widgets

Keep agent activity and remaining quotas in your peripheral vision across desktop spaces and Notification Center.

  • Three Dedicated Widget Families Choose from Loom Sessions, Loom Quotas, and Loom Usage Overview across Small, Medium, and Large families.
  • Configurable Provider Targeting Monitor all enabled providers simultaneously or configure a widget to follow a specific coding agent via native Edit Widget controls.
  • Native WidgetKit Fidelity Built with pure SwiftUI for macOS Sonoma. Adapts automatically to Light, Dark, and desktop tinting modes with zero CPU overhead.

Security & Architecture

Built for Developer Privacy

Loom is crafted with a strict local-first architecture to protect your code and credentials.

No Accounts, Zero Telemetry

There is no sign-in, no Loom user database, and no cloud server. Loom embeds zero tracking, analytics, or behavioral telemetry frameworks.

Strictly Read-Only Inspection

Loom never executes prompts, writes code, modifies agent sessions, or approves dangerous CLI operations. It inspects local runtime state purely for monitoring.

Ephemeral Memory Tokens

Loopback authentication tokens for Google Antigravity language-server endpoints are retained strictly in memory and are never written to disk or logs.

Path Concealment Mode

Mask absolute filesystem paths and project folder evidence across all menu views with a single toggle in Settings (⌘,) during presentations and recordings.
